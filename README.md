# Gym Tracker

تطبيق ويب احترافي لتسجيل تمارين **المقاومة** و**الكارديو**، بتصميم داكن على طراز لوحة سيارة رياضية (Performance Cockpit). الواجهة **عربية RTL** مع تبديل فوري إلى **الإنجليزية LTR**.

## المزايا

| الميزة | التفاصيل |
|---|---|
| صفحة عرض عامة | عرض قدرات التطبيق للزوار، مع عدّاد كارديو حي (عرض توضيحي) ومكتبة التمارين |
| حساب خاص لكل مستخدم | إيميل + كلمة مرور عبر Supabase Auth، وكل مستخدم يرى بياناته فقط (RLS) |
| وضع المقاومة | اختيار التمرين، وتخطيط المجموعات (تكرارات ووزن لكل مجموعة على حدة)، وشاشة تدريب غامرة، وتأكيد القيم **الفعلية** لكل مجموعة |
| مؤقت الراحة | 30 أو 60 أو 90 أو 120 ثانية أو مدة مخصصة، و+15 ث، وإيقاف واستئناف وتخطٍّ، وتنبيه صوتي واهتزاز عند الانتهاء |
| عدّاد الكارديو | قوس 280° على طراز عدّاد السيارات، **الوقت هو البطل**، مع إيقاف واستئناف وإعادة ضبط مع تأكيد، وتصحيح المدة قبل الحفظ |
| الأرقام القياسية | **قاعدة البيانات** تتحقق من كل رقم قياسي (Trigger)، فلا يظهر رقم جديد إلا إذا كان أثقل فعلاً |
| السجل | فلترة حسب الفترة والتاريخ والنوع والتمرين، مع تفاصيل كل جلسة (للعرض فقط) |
| موثوقية | المؤقتات مبنية على الطوابع الزمنية، فلا تتأثر بتبديل التبويب أو تحديث الصفحة. الجلسة النشطة تُستعاد تلقائياً. طابور حفظ يعمل بدون إنترنت **بلا تكرار** |

## التقنيات

Next.js 16 (App Router) · TypeScript · Tailwind CSS 4 · Supabase (Postgres + Auth + Storage + RLS) · Motion · Lucide

## التشغيل محلياً

**المتطلبات:** Node.js 20 أو أحدث.

```bash
npm install
cp .env.example .env.local   # ثم ضع رابط المشروع والمفتاح العام
npm run dev
```

افتح http://localhost:3000

**متغيرات البيئة** (قيم عامة فقط، ولا يوجد أي مفتاح سري):

| المتغير | القيمة |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | `https://<project-ref>.supabase.co` |
| `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` | المفتاح العام `sb_publishable_...` |

> ⚠️ لا تضع أبداً مفتاح `service_role` / `secret` أو كلمة مرور قاعدة البيانات في هذا المشروع.

**إعدادات Supabase المطلوبة:** من Authentication ← Sign In / Providers:
- **Allow new users to sign up:** مفعّل.
- **Confirm email:** مُطفأ، إلا إذا ربطت خدمة بريد (Custom SMTP).

## الأمان

- **حماية من قاعدة البيانات:** RLS مفعّلة على كل الجداول، وكل مستخدم يقرأ ويضيف **بياناته فقط**. لا يوجد حذف، والجلسات المكتملة لا تُعدَّل.
- **مفتاح عام فقط:** المتصفح يستخدم المفتاح العام فقط، والحماية من قاعدة البيانات نفسها وليس من الواجهة.
- **لا تكرار:** كل مجموعة تأخذ معرّفاً من الجهاز قبل الإرسال، وقاعدة البيانات تمنع تكرار `(session_id, set_number)`.
- **تسجيل الخروج آمن:** ممنوع ما دامت هناك تمارين لم تُحفظ، فلا تختلط بيانات مستخدمين على نفس الجهاز.
- **لا ادعاءات بدون حساسات:** التطبيق لا يدّعي قياس السرعة أو النبض أو السعرات. المسافة يدخلها المستخدم.

## النشر على Vercel (لاحقاً)

1. **استورد المستودع:** استورد `ABF90/gym-tracker` في Vercel.
2. **أضف متغيرات البيئة:** `NEXT_PUBLIC_SUPABASE_URL` و `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`.
3. **أضف رابط الموقع في Supabase:** في Authentication ← URL Configuration، أضف رابط Vercel في **Site URL** و **Redirect URLs** (`https://<your-app>.vercel.app/auth/callback`).
4. **انشر.**
